The model

Global Data Model

The model is a normalized field catalogue for online illegal wildlife trade (IWT) monitoring. It separates universal fields that every program should capture from conditional fields that depend on the investigation objective, platform type, or collection capacity.

How it was curated

Evidence-informed field selection

The catalogue is organized around practical monitoring decisions: what was observed, where it was observed, who posted it, how it was traded, and how confidently it can be interpreted. Field definitions emphasize repeatability and defensibility so independent teams can compare outputs without forcing every team to collect unnecessary detail.

  1. Harmonize terms. Similar fields are merged into a common label and plain-language definition.
  2. Assign collection status. Fields are marked as required, recommended, conditional, or optional.
  3. Map decisions. Each field is tied to the program questions it supports, such as species identification, seller behavior, enforcement triage, or trend analysis.
  4. Reduce risk. Sensitive or personally identifying data is scoped to the minimum needed for a legitimate monitoring purpose.

Use the model as a living protocol

Before collection starts, export a scoped field list, document inclusion and exclusion decisions, and revisit the list when platforms, taxa, legislation, or program goals change.

Platform assessment

Platform assessment compares channels using the same criteria before a team commits time to manual review, scraping, or partner data requests. Scores are meant to support prioritization, not to label a platform as inherently high or low risk.
